# 数据说明

数据只保存在设备本机。导入、恢复、清除前请查看应用内的预览和确认。

- 全量原生 JSON：保存完整账本、账户、计划、分类、借贷、设置及跨模块关联。当前 schema 为 7，支持读取旧 schema 1—6。
- 原生模块 JSON：可分别导入/导出记账或现金流模块；只替换选定模块，另一模块保留。完整跨模块关联请使用全量备份。
- CSV/XLSX：支持按日期、分类及债务字段迁入；预览重复、错误和待创建分类。相同来源重复导入按来源标识防重，不能保证任意手工改写的文件仍被识别为同一记录。
- 现金流 JSON：兼容 [啥时候有钱](https://github.com/7panni/show-me-the-money) 的 v6 交换格式。原应用不能表达的币种、关联或兑现方式不能假定无损互通。

默认历史导入不会再次扣减当前余额和预算。借贷本金与普通收入/支出分开，同人往来保留每笔明细和归还分配。

记账清除与现金流清除分别确认。账户校准不是普通收入/支出；美元和数字币的首页估值也不写成实际收支。请勿把个人账本、备份或真实截图提交到公开 Issue。
